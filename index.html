Enrol & Verify Farmer

New farmer enrolment

Field agents enrol farmers here. Before an account is created, the system checks the national ID records and our own registry so the same person can't open a second account.

Verification result

What the system checks, in order:

  1. ID format is valid (NIN 11 digits, BVN 11 digits).
  2. ID is confirmed against the national database through a licensed verification provider; name must match.
  3. ID fingerprint is compared with every farmer already in the registry, across all projects and countries.
  4. Phone number is checked so one SIM can't front several farmers.
  5. Only if all pass: a unique Farmer ID is issued.
Fill the form and press Verify & Enrol. Tip: tap Try a duplicate to see the system block a second account.

Credit Scores

Because each farmer has exactly one record, their history follows them from project to project. The score (300–850) is built from repayment record, documents provided, seasons completed, yield delivered against target and training attended. Tap a farmer to see the breakdown.

FarmerScoreBand

How the Score Is Calculated

Every farmer starts at 300. Up to 550 more points come from five factors, weighted as below. After repayment history, the documents a farmer provides carry the most weight, and each one is checked by a LAICOS FARM officer before it counts.

Documents Farmers Can Provide
